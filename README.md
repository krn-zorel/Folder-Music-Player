# Folder Music Player

A simple, distraction-free Android audio player designed around local directories rather than streaming services or algorithms.

> Most music apps today focus on recommendations, social feeds, and cloud sync. This project was built to get out of the way and let you listen to the music files you actually own.

---

### Why this exists

If you keep carefully organized music folders on your phone, standard player libraries often mess up tag metadata, mix up album art, or demand unnecessary internet access.

This app treats your file system as the primary source of truth:
* **Your folder structure stays intact:** What you see in your storage is what plays.
* **No network footprint:** Zero tracking, zero telemetry, and no remote dependencies.
* **Resilient playback:** Uses modern Android Media3 APIs so playback remains stable in the background during calls or screen lock.

---

### Built with

* **Language:** Kotlin
* **User Interface:** Jetpack Compose
* **Audio Core:** AndroidX Media3 (ExoPlayer)

---

### Getting Started

1. Clone or download the repository.
2. Open the project in Android Studio.
3. Build and run on any device running Android 7.0 (API level 24) or higher.
